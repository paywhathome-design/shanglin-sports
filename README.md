# 上林神寵運動養成系統 (Shanglin Divine Pet Exercise Development System)

> 國小健康促進 × 運動紀錄 × AI 神寵分支進化  
> 視覺風格：浪漫粉彩 × 極致可愛呆萌（櫻花粉、薰衣草紫、晨曦琉璃藍、薄荷綠、柔光蜜桃粉）

## 🌟 系統亮點特色

1. **浪漫呆萌粉彩美學體系**
   - 採用 **櫻花粉 (`#FF758F`)**、**薰衣草紫 (`#9D4EDD`)**、**晨曦琉璃藍 (`#48CAE4`)**、**薄荷綠 (`#52B788`)** 與 **柔光蜜桃粉 (`#FFCAD4`)**。
   - 圓潤棉花糖卡片、呆萌微笑瞇瞇眼 `(> ‿ <)`、粉嫩微光光暈與流暢彈跳微互動。
2. **趣味音效互動**
   - **摸摸撒嬌**：點擊神寵觸發彈性晃動，神寵發出可愛呼嚕咕嚕聲與鳴叫，瞇眼笑並冒出「啾~♥」、「呼嚕嚕~✨」等愛心粒子。
   - **咀嚼餵食**：餵食運動吸收的四大能量球，神寵做出咀嚼動畫 `( ˘ω˘ ) 嚼嚼嚼~` 並發出清脆咀嚼音。
   - **奇蹟蛻變盛典**：累積 EXP 突破進化門檻時，彈出全螢幕慶典，Web Audio API 即時奏響「星光和弦與豎琴琶音」！
3. **100% 嚴格落實 PDF 官方核心遊戲規則演算法**
   - **四大能力能量分離**：耐力 (❤️)、肌力 (💪)、敏捷 (⚡)、協調 (🎯) 象徵神寵吸收的養分，非評分。若為 0 則顯示「敏捷能量尚在沉睡中，等候探索✨」。
   - **官方 13 種運動玩法對應**：球類、跑步、飛盤、腳踏車、扯鈴、跳繩、拍球等，主次能力約 2:1 精確小數分配，學生不自行選能力。
   - **時間與喘度矩陣**：輕鬆／有點喘／很喘 × 時間區間，精準查表對應 Lv1～Lv5 與 2/4/6/8/10 能量。
   - **個人挑戰 Bonus 獨立計算**：低於(+0)、一般(+0)、進步(+1)、挑戰(+2)，嚴格只加成長 EXP，不進入四能力、不影響外觀比例，每日上限 +2。
   - **防刷與每日 10 點上限**：同日多筆合併，四能力上限嚴格鎖定 10.00 點（超出時依原比例縮放）。
   - **每週 12 EXP 成長保護**：每週最終成長 EXP 上限 12，守護學生健康節奏。
   - **七大進化階段**：蛋 (0-7) ➔ 孵化 (8-24) ➔ 幼年 (25-59) ➔ 成長 (60-104) ➔ 進階 (105-159) ➔ 階5深化期 (160-224) ➔ 階6最終期 (≥225)。
   - **能力結構判定與飾品機制**：四項均衡（≤15%）、三能共振（≤12%）、單主專精（≥50% 或差額 ≥20%）、雙能交織；當第 3 能力 ≥15% 時自動佩戴浪漫飾品（心動光環、星願音符、飛羽緞帶、小勇士披風）。
   - **進化穩定機制**：新主能力領先舊主能力 ≥8% 或連續兩次領先才更動主方向；幼年期確立物種、成長期鎖定。
4. **健康促進指標看板 & 5 階段生命樹 (PDF-TREE)**
   - 累計每週中高強度運動（MVPA，目標 ≥150 分鐘/週）。
   - 每日 60 分鐘活動目標天數（連結 WHO / 教育部兒童運動指引）、肌力天數與運動多樣性。
   - 依據 PDF-TREE 繪製生命樹五階段：綠色嫩芽 ➔ 成長幼苗 ➔ 挺拔綠葉小樹 ➔ 繁茂大綠樹 ➔ 歡樂森林樹屋遊樂園（配有溜滑梯、鞦韆與遊玩小朋友）。
5. **神寵圖鑑 (PDF-2)**
   - 收錄 5 大蛋系（美德-烈焰、健康-碧浪、生態-森靈、樂學-雲翼、韌性-暗影）全 6 階段與 35 隻神寵分支外觀與設定。
6. **教師模擬實驗室**
   - 支援時間快轉 1 天、快轉 1 週（驗證每週 12 EXP 上限重置）。
   - 直接進化測試、防刷 10 點上限比例縮放壓力測試、浪漫飾品觸發測試。
7. **多使用者與全校健康大數據**
   - 學生與教師自由新增註冊與即時切換，資料獨立保存，並支援全校匯總統計。

## 🚀 執行與測試方式

本專案為純前端獨立系統，無任何外部不穩定相依套件，可在任何現代瀏覽器直接開啟：
1. 以瀏覽器直接開啟專案目錄中的 `index.html`：
   `file:///C:/Users/user/.gemini/antigravity/scratch/shanglin-pet-system/index.html`
2. 亦可於本地透過簡易 HTTP 伺服器啟動：
   ```bash
   npx serve C:\Users\user\.gemini\antigravity\scratch\shanglin-pet-system
   ```
